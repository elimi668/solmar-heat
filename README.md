Solmar Heat is a 2D top-down open-world crime game set in the sun-soaked coastal city of Solmar City: steal cars, outrun the police, and run a three-job delivery chain — all in a desktop browser, offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
